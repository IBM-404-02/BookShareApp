# Читай, Пиши и не спиши 

**Прототип десктопного приложения для обмена книгами** — учебный проект по практике УП.01.01  
Специальность: 09.02.07 «Информационные системы и программирование»

## О проекте

Приложение представляет собой платформу, где маленькие авторы могут публиковать свои книги, а читатели — находить, читать, оценивать и вести личные списки чтения.

### Основные возможности

- **Авторизация и регистрация** (3 роли: Пользователь, Автор, Администратор)
- **Каталог книг** с поиском, сортировкой и фильтрацией по жанрам
- **Страница книги** с полным текстом, отзывами и оценками
- **Личные списки чтения**: В планах, Читаю, Прочитано, Заброшено
- **Авторский кабинет** (публикация и редактирование книг)
- **Административная панель** (модерация жалоб, заявок, заморозок)
- **Система жалоб, заморозок и апелляций**

## Технологии

- **Язык**: C#
- **UI**: Windows Presentation Foundation (WPF)
- **.NET Framework**: 4.7.2
- **База данных**: Microsoft SQL Server (Entity Framework)
- **IDE**: Visual Studio 2022
